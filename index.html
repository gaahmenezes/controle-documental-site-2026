    Cobertura da obra

    Cada quadrado é uma casa. Toque para abrir a ficha — ou, nas casas sem ficha, para iniciar uma. Considera que cada FVS se aplica a todas as casas da obra.

    Preencher documento

    Escolha a ficha, informe a unidade e registre o resultado e a data de cada item. O preenchimento é gravado automaticamente; use "Salvar" a qualquer momento para confirmar.

    Preenchimentos

    Fichas já iniciadas nesta obra, agrupadas por documento. Abra para continuar ou gere o documento preenchido quando todos os itens estiverem completos.

    Nenhuma ficha iniciadaAbra um documento na aba Preencher.

    Repositório

    Área restrita à conta de controle. Envie um ou vários documentos de uma vez; cada arquivo é versionado, assinado por impressão digital e, quando é uma planilha (.xlsx/.xls), tem o questionário gerado automaticamente.

    Arraste os arquivos aqui ou clique para selecionar PDF, DOCX, XLSX, DOC, XLS, ODT, TXT, CSV — vários de uma vez, até 20 MB cada
